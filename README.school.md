# School AI architecture

Skeleton's school layer is the portable intelligence core for Tutolage/Jeeves. It keeps learner state, curriculum, assessment, adaptive control, memory, pedagogy, co-coding, and code-intelligence policies independent from web frameworks, model providers, vector stores, and deployment infrastructure.

Tutolage's advanced code-intelligence surface is represented as deterministic signals and learning tasks so coding itself can generate evidence for Jeeves' mastery loop.
