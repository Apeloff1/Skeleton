# Forge Studio: 50 trillion composable source actions and ten billion virtual manuals

This Epic Variation expansion **actually implements** ten additional topology algorithms and a bounded multi-layer authored-world transaction in the canonical `StudioProject`. It inherits all preceding Saga, Epoch and longform production systems. Counts are virtual registered source combinations, NOT independently built games, assets, engines, weight checkpoints, or verified playable releases.

## Physical source implementations

- `skeleton/forge/game_frontier_studio_epic_variations.py`: 45,000,000,000,000 exact ranked variations; optional up to seven named extra existing layers, deterministic geometric patterns, typed observed-event page, only-new actor staging and optional only-new quest routes; no additional storage authority.
- `skeleton/forge/game_frontier_studio_authoring.py`: 50T exact total across eleven indexed generations, dispatch and canonical candidate SHA receipts. Previously registered 5T identities remain stable.
- `backend/routes/game_frontier_authoring.py` and `backend/core/game_frontier_authoring.py`: authenticated indexed search and book read/rank, existing version-owned CAS persistence.
- `frontend/src/product/gameFrontierAuthoringClient.ts` and Jeeves authoring/handbook panels: strict source contracts, mode selectors and real book comparisons.
- `skeleton/forge/game_frontier_studio_epic_handbooks.py`: 9,000,000,000 exact on-demand Epic books. Including preceding families, total addressable catalogue becomes **10,000,000,000**, not a giant Git file tree.
- `scripts/export_game_studio_epic_handbooks.py`: materializes 1–100 real, hashed documents with no silent overwrite, and ranks only that physical batch.

## Epic-specific source transaction

A caller may pass `epic_layers: ["existing_a", "existing_b"]` in the already bounded Forge edit parameters. These layers must be original project layers, distinct from the primary `layer`, and the same rectangular edit must fit every selected layer. All affected layers validate floor/wall palette index. Only the named layers are touched; old cast and quests persist. No write happens until the host approves the candidate source revision.
