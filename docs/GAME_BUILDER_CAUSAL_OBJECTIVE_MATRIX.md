# Objective-driven adversarial original-game world design matrix
**Authored:** 2026-10-12, Europe/Oslo. **Stack:** verified what-if original world #3704 → original event-clock source save #3701 → original 49-cell cross-engine NPC simulation.

## What changes in actual game creation
The studio now provides a **source-measured multi-objective comparison** for original game event ordering, using physical incidents, real farm harvests, maritime cargo, aircraft landings and player NPC actions. The assistant does not invent storyline success or label every reordering a feature improvement: it independently replays the original world and evaluates actual player-facing effects.

Game creators can choose between five explicitly named and mechanically measurable world-design axes: **credible eyewitness reach** (number of NPCs retaining firsthand memories), **earned quest completions**, **original site restoration** (remaining structural integrity), **finite material resilience** (true site stock plus finite player supplies) and **secondhand rumor reach** (NPCs carrying rumor memory). A creator selects one to four ordered goals, defining the review priority without arbitrary aesthetic quality weights. The metrics are not universally desirable: more rumor propagation may be right for intrigue or wrong for secrecy; the author chooses objectives.

## Genuine original-source verification
Every source scenario first passes the complete independently reconstructed interleaved Physics/genre/NPC world laboratory. Each candidate receives a complete measured difference ledger relative to the original source-authenticated baseline. Objective scores are derived ONLY from those authenticated baseline and counterfactual snapshots; neither an AI description nor client-submitted health, testimony or quest status can provide an unearned positive value.

The report classifies each source-verified alternative into one of four outcomes: **strict real-gameplay improvement** (at least one authored goal improves and none regress); **explicit gameplay tradeoff** (some goals improve and others worsen); **verified gameplay regression** (no authored goal improves and at least one worsens); or **no measured gameplay gain** (all chosen goal values unchanged). Source-invalid candidates have a separate classification and no invented world metrics.

## Pareto comparison and safe priority
A scenario is on the reported Pareto frontier only if neither the baseline nor another source-verified scenario is at least as good in every chosen objective and strictly better in at least one. This identifies nondominated tradeoffs but deliberately does NOT claim they are all objective improvements. A suggested alternative is selected **only from strict improvements**, using a stable lexicographic comparison of actual deltas in the creator's chosen goal order. When no strictly better scenario exists, the result suggests **nothing** instead of promoting a superficial reorder.

Each candidate retains its independently authenticated source-world digest, exact measured goal values and deltas, reviewed classification, Pareto classification and a chained SHA-256 entry. The matrix itself has a final digest and may be independently replayed and compared. Source hashes provide deterministic provenance, not a cryptographic author identity signature.

## Studio
The game Studio adds an original-world design objective editor with a reviewed starting goal list and the action **Compare verified playable game outcomes, not just event order**. The result displays all authentic baseline metrics, measured candidate values, strict improvements, Pareto/tradeoff status, invalid source orders and a suggested candidate **only if strictly better**. The user must still inspect an alternative in the existing what-if laboratory, manually copy that signed timeline to the game editor and run the full original world simulation before any game event changes.

## Adversarial testing
Eight new executable engine tests include no free improvement for reordered but equivalent worlds, ordered creator goal selection, bounded/typed goal guards, true Pareto mathematical dominance, actual maritime resource conservation against an independent original engine run, source corruption, forged scoring/promotion, and complete verified metric shape. Three Studio tests verify real creator controls, human-only acceptance, explicit negative release/weight flags, and independent server proof.

## Known limitations
This is a deliberately bounded, transparent multi-objective original **gameplay** comparator, not professional blind playtesting, a model gradient trainer, generalized search over arbitrary millions of worlds, a universal aesthetic ranking or native simultaneous multi-engine proof. More realistic user experience metrics require trustworthy player telemetry and structured playtesting. No original user project files are written, no model permanent weights are promoted and no game is published automatically.
