# Adversarial mirror for original cross-engine NPC world outcomes
**Authored:** 2026-10-12, Europe/Oslo. **Parent:** replay-only event-clock world saves #3701; original deterministic interleaved game-world runtime #3699.

## Real counterfactual execution
Game creators may compare two to six independently replayed authored event clocks for the same original source games. This is not a text-only conjecture: **each candidate timeline is separately reconstructed** by the authoritative interleaved world engine, which replays signed physical source incidents, actual farm/ship/flight achievements and canonical NPC world actions. The full counterfactual world includes real NPC direct memories, rumors, site integrity/stock, finite player supplies, quest activity, and source-local physical/genre evidence.

Inputs must share the same underlying physical episodes, source genre sessions, authored world scene and world settings. Each candidate must also have the same multiset of NPC world actions, so a claimed improvement cannot be due to quietly dropping a costly repair or adding free assistance to one arm. Every source event is required exactly once and source chronology, clock ticks and actual action authority must pass independently for each arm.

## Explicit, honest scoring
An author selects exactly one of four narrow world metrics: total material site integrity; count of retained firsthand NPC memories; available player supplies; or number of actually completed NPC quests. Results include the complete observable world ledger for each arm and factual differences from the first baseline: integrity, NPC knowledge, world supply/gold, completed quests, elapsed ticks and NPC quest-origin/order changes. Rankings use descending integer values for **that one selected objective**, with deterministic scenario-name tie-breaking. They do not assert general game quality, playable perfection or AI model improvement.

## Source and proof custody
Typed JSON scenarios require unique lowercase names, at most six scenario slots and 96 entries per clock. The engine rejects fabricated timestamps, source inserts/omissions, forged scene/genre sessions and altered event receipts through full independent replay. A canonical SHA-256 chain binds each actual scenario source timeline, verified replay digest, metric vector and differential against the prior chain head. The final verifier independently recreates the same entire laboratory and compares every ranking and source ledger. No original game projects, permanent AI weights or consumer game saves are modified.

## Local Studio
The authenticated Studio now offers a counterfactual builder that swaps two neighboring original physical/genre events as a reviewable starting candidate. Users can edit two to six full timelines and choose one explicit metric. **Independently replay and compare actual NPC outcomes** invokes the server's independent event clock for every candidate, then displays narrowly defined rankings, exact gameplay differences, source receipt counts and a final replay digest. The output explicitly marks universal AI improvement as unproven.

## Adversarial validation
Eight engine tests cover genuinely different source event orders, real NPC quest-origin differences, four factual metrics, deterministic replay and source proof chains, matching gameplay action multiset, immutability of original sources, forged metrics/rankings, malformed scenario complexity and swapped real physics/farming input. Three Studio/API tests cover actual operator controls, safe factual scope, same-origin server independent verification and release disclaimers. Full Windows/Ubuntu advanced-engine and native reference parity workflows are retained.
