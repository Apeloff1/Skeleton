# Original character arcs — reviewed choice-to-ending transformations

Character arcs are a distinct original narrative plane built on canonical
world choices and the reviewed NPC cast. Each actor has a desire, starting
belief, resolved belief and authored choice-triggered beats. The bounded
continuity proof explores reachable choice/flag states and rejects every
ending path that leaves an arc unresolved, unreachable beats, missing cast
presence, duplicate beat IDs, unreviewed publication and stale source digests.

Prompt → \`world-character-arcs propose\` returns a typed **unapproved**
source. \`save --create --source-json JSON\` persists it under the canonical
world lease. \`edit --expected-digest SHA --operation-json JSON\` makes an
optimistic typed change and clears approval. \`approve --expected-digest SHA
--review-note TEXT\` requires reviewed cast and all ending proofs. \`editor\`
emits a CSP-protected offline JSON export editor. \`compile\` emits a playable
HTML5 preview, typed engine recipe, and tamper-evident receipt. \`verify\`
recomputes exact source/receipt/artifact identities under a single lease.
\`player --slot SLOT\` replays an existing canonical session through actual
authored arc beats. Read-only Jeeves previews cannot approve or publish.

All content is authored from user prompts and operator edits. No network,
dynamic code execution, untrusted HTML insertion, or unlicensed assets are
required. This is a source-level narrative/gameplay handoff, not a device or
release qualification. Exact-head focused tests and mandatory CI remain
required before promotion.
