# Seven additional source-verified game studio milestones

This batch extends the existing Jeeves expedition campaign compiler and the
existing source-verification runtime. No parallel gameplay authority, new service,
or provider boundary has been introduced.

1. Directed world topology: reachable authored nodes, non-goal sinks, goal cuts.
2. Fictional navigation instruments: virtual compass, altimeter and sextant.
3. Four objective routes: actually executed source gameplay and Pareto comparison.
4. Seven weather stress variants: gameplay under wind, rain, turbulence, updraft
   and low visibility both with and without navigation gear.
5. Coherent frames: bounded easing targets with per-frame hash-linked chain
   pinned to canonical verified gameplay. Not native rendered video.
6. Original asset resource review: exact OBJ byte hashes and complete per-node
   LOD accounting with upper/lower triangle budgets. Not real GPU benchmarking.
7. Delivery scrutiny: independent recomputation of all six source reports and
   explicit blockers for absent native evidence, rights review, physical input
   qualification and measured multimonth operations.

The campaign compiler exports seven JSON reports under
game/frontier/qa_seven, and binds the delivery receipt into its top-level
source manifest. The CLI reports the same source review result. A new
adversarial regression suite checks tampered geometry, tampered acceptance
receipts, invalid virtual-instrument limits and foreign source bindings.

The repo must still pass exact-head CI and real device/engine/legal gates
before release. These sources do not automatically sign production approval.
