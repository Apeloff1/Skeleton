## Studio Engine optional narrative planes

The canonical nine-plane Studio Engine recipe can additionally include
reviewed chapter/act structure and reviewed original cinematic storyboards.
These are optional, but when either source file exists it must be valid and
**approved**; an unreviewed optional source blocks compilation rather than
being silently omitted. Every read occurs under the same world-wide source
lease as the nine required planes.

\`world-studio-engine inspect\` returns \`optional_planes\` and exact digests
for both optional sources. \`compile\` requires the complete matching digest
map, including optional sources. The manifest enriches every scene node with
the authored chapter index and cinematic beats and includes typed optional
engine handoffs, while preserving the existing choice graph, chronology and
accessibility planes. A newly added or revised optional source invalidates
prior compiled receipts until recompiled.

No optional source changes the mandatory nine-plane schema or relaxes
source provenance, review, device qualification, or release holds.
