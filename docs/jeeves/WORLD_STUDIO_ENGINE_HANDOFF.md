# Original Studio world → typed engine handoff

This integration delivers an actual source-bound builder/engine recipe,
not a static game catalog. It composes the reviewed seven-source Studio
HTML5 assembly with original, rights-attested asset briefs and canonical
temporal events under one descriptor-anchored world lease. The engine
manifest includes typed scene nodes, choices, endings, localized authored
text, accessibility descriptors, pacing, NPC testimony, causal rumor
routes, cast dialogue, original engine asset recipes and logical-tick
temporal events. Every field is tied to nine source digests and the Studio
cross-plane proof. It does not contain executable code or private notes.

The operator `python -m skeleton world-studio-engine --store DIR inspect
--world-id ID --era eight_bit_tile_1983` returns source digests for an
exact-lease `compile --expected-digests-json JSON` call. Compile writes
the deterministic engine manifest and publishes a receipt last; `verify`
recompiles the exact engine recipe and compares artifact bytes. A changed
world, unreviewed Studio plane, unreviewed asset, invalid era, symlink or
tampered manifest fails closed. Typed Jeeves preview is read-only.
The engine handoff is not a built executable, device or release proof.

Focused regression: `python -m pytest skeleton/testing/test_jeeves_world_studio_engine.py -q`.
