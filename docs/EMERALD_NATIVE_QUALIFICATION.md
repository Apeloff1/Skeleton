# Emerald native experimental integration
The pinned browser pack is the presentation path in the existing crawler. The native character is an independently staged optional project, not a second AI runtime or a required first-install dependency. No runtime automatic launch, new credential, or scheduler. All 380 skeletal clips and 108 joints in the current fold revision are retained; archive case is disabled, continuous clearance and artist signoff outstanding.

From the repository root, stage the two separately distributed exact files:
```sh
python scripts/stage_emerald_native.py /path/emerald-atelier-fold-source.zip /path/emerald_continuum.glb
```
On a Windows host with an installed licensed Unreal Engine and compatible compiler, review the extracted source, then invoke:
```powershell
powershell -File artifacts/emerald/native-v1/Unreal/Tools/qualify.ps1 -EngineRoot 'C:\Program Files\Epic Games\UE_5.8' -RunHardware
```
Use the actual installed engine version if compatible with the source. Verify reported receipts using:
```sh
python scripts/inspect_emerald_native_receipt.py path/to/qualification_RUN.json
```
No unattended download/installation or cloud execution. Stage receipt isn't engine evidence; editor NullRHI is not GPU evidence; a trace hash is not proof of ray dispatch; tick cadence isn't presented frame cadence. Validate present/GPU timing, ray dispatch, BLAS updates, full authored texture residency, deformation and artistic reference comparisons independently on RTX 30-series+ hardware. Current status: source-only, uncompiled, no physical RTX acceptance. Never turn on experimental equipment by default. Rollback: remove staged native directory after stopping Unreal; no mutation of canonical app state.
