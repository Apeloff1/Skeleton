# Game Studio — Three-Engine Social and Quest Fusion

Date: 2026-10-12 (Europe/Oslo). Status: draft, exact-head CI required.
Dependencies: native Dialogue #3680, Dialogue #3677, causal repairs #3675 and the Game Studio parent.

## Real game mechanics

This milestone adds an executable original narrative across three already
playable engines, not merely a descriptive assembly graph.

A real Quest Director event requires player walking, finite material costs,
an authored site and direct eyewitness memory. A bridge interview additionally
runs physically local NPC Society conversation and a directly heard Dialogue
speaker. Original authored narrative IDs bind sources by role, while retaining
their separate physical positions and provenance; rumors cannot act as
eyewitness statements.

A bridge pledge spends real Dialogue influence, changes trust and reputation,
performs NPC Society help at a material cost, and commits the genuine Quest
Director support branch. NPC Society residents have work/home schedules, so the
bridge uses bounded actual walking to pursue a moving person rather than
teleporting an NPC or silently awarding assistance.

An earned composite social resolution requires a material Quest Director
followup and true resolved outcome, Dialogue consensus from separate direct
sources, and physical NPC Society assistance. It records a nonterminal
cross-world narrative milestone without inventing any original-engine rewards.

## Source integrity and limitations

- Strict authorized original scenes, typed settings and seed identity.
- Maximum 64 bounded composite commands; maximum 128 actions per game engine.
- Reexecute all three engines from original actions. Exact source receipt and
  replay-head digests are recorded for each subsystem and every bridge.
- Full story receipt is independently recomputed; altered quests, resources,
  origin events, trust, branches, reward or references are rejected.
- No source project mutation, automated AI training weight promotion, or
  certified native unified executable.
- Distinct game coordinate systems are declared explicitly. A role association
  is NOT proof that a person inhabits the same exact geographic body in all
  three independent engine maps. A unified spatial authority remains future
  work.

## Practical user and developer interfaces

- Advanced social quest fusion engine: original narrated and causal actions.
- Offline CLI: social-quest-fusion with JSON commands, settings, authored
  scenes and seed; verify-social-quest-fusion reexecutes all proofs.
- Local token-protected Studio HTTP routes to simulate and verify.
- Visual Studio dialogue area presents editable composite commands and
  cross-engine actual states, original witness receipts, social consequences,
  player approval and reverified narrative outcomes.
- Standalone Ubuntu/Windows exact-head CI and adversarial tests across
  source worlds, forged testimony, remote NPCs, finite costs and tampering.
