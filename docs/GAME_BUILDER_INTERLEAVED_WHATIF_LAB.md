# Adversarial original-game world timeline laboratory — causal gameplay, not speculative scores
**Authored:** 2026-10-12, Europe/Oslo. **Stack:** independently replayed interleaved event clock #3699 → portable source-only saves #3701.

## Verified experimental mechanics
Game creators can now replay alternative **event admission orders** for the same independently validated original physics, farming, sailing, flight and NPC-world source inputs. This does not ask a provider model to predict story outcomes. Every candidate is re-executed through the canonical interleaved world engine, including original source fixture collisions, independently earned genre action events, real eyewitness line-of-sight, actual NPC movement/rumors and finite quest/material economy.

The laboratory first independently verifies the entire original baseline world. It then generates up to 12 canonical adjacent-causal swaps, preserving every input source event and source-local action index; it never drops, fabricates or duplicates achievements. Adjacent swaps of two events in the same source lane/index are not proposed, so one source's chronological event order is respected. Each derived admission time is computed from the original signed world action durations; if timing changes or the new order is invalid under the actual game engine, the candidate is explicitly marked invalid, with **no claim of an improvement**.

## Evidence to compare
For each **successfully and independently replayed** alternative, the laboratory records actual changed dimensions and exact baseline/counterfactual values for: NPC event actor/kind/site/tick and firsthand witnesses; current world time and player location; finite supplies, stamina, reputation and gold; per-site structural integrity and stock; eyewitness memory, secondhand rumor memory and rumor edge count; actual NPC trust/suspicion; individual quest origins/status/choices/testimony/material followups; earned quest completions/exploit outcomes and original terminal state.

These are measured differences, **not a subjective quality score, causal proof about untested policies, or evidence that an AI model's weights improved**. A candidate may have identical final resources yet differ in witnessed NPC history and storyline origins. The report makes this distinction explicit by naming precise changed dimensions. Multiple genuine counterfactuals are evaluated against the **same** starting source history and independently replayed world state, not against changing test baselines.

## Anti-adversarial controls
Reviewable limits: at most 12 alternate executions per request and at most 96 original game-world timeline entries. Each candidate includes its exact alternative schedule, source campaign digest, full authenticated replay digest (only if valid), changed dimensions, exact world-state hash and chained SHA-256 record. Invalid source orders never receive a campaign hash, positive effect score or automatic promotion. A verifier reconstructs every candidate and compares the entire result. Modified facts, forged site gold/stock, altered witnesses or story progress, fake success flags, changed source game data and fake weight-promotion status are rejected.

## Game Studio
The Studio provides a bounded trial count, **Compare source-verified world event orders**, a list of valid versus invalid alternate outcomes and a detailed original NPC-difference view. The user may choose a genuinely replayable alternative and copy its authored schedule into the existing timeline editor. This simply prepares an alternative for review; it clears old approval/save receipts and requires a separate full `Replay authored cross-engine event timeline` action before game changes are accepted.

## Validation and release
Nine new source-backed gameplay tests check real source-preserving alternative causality, actual chronology-dependent quest effects, maritime resource conservation, invalid-trial exclusion, NPC memory differences, finite budgets, untrusted source alteration and forged improvement claims. Three Studio/API tests cover actual what-if controls, manual selection, same-origin proof and no automatic AI weight promotion. All are in the exact-head Windows/Ubuntu game engine suite; native Godot source physics parity is a separate gate.

This laboratory covers deterministic event-level reference gameplay. It does not reproduce a native frame-synchronized multi-engine system, train a new model by itself, guarantee authorial quality, grant autonomous optimization rights, or issue hardware certifications. Source hashes are deterministic evidence, not secret-key signatures.
