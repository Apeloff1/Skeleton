# Emerald V7 exact original offline qualification conveyor

This source-built operator workflow is the missing closure between **original binary custody**, the original **V6→V7 animation-change verification**, the **five original reviewed contact-analysis sources**, and the **full 108-pose expanded crossfade screen**. It is not a shipping/runtime feature and never changes the installed model.

## Complete source inputs

- `pathfinder-v7-orbit02-clearance.zip`, `archivist-v7-orbit02-clearance.zip`: each ZIP and every raw slice and full 114.7/114.8 MB GLB must match the independent publication manifest pinned SHA-256.
- Original **V6** GLBs, one per stage: Pathfinder exactly 114,693,124 bytes / `20d6a6a62b3ff232572e1b25d799f1461d4e343ce3b7d30a328faed8837c4063`; Archivist exactly 114,815,776 bytes / `8d72d43773a98444133ab628db552bddad06ea0f101cfe223897bf8ba0944973`.
- Retained `source-and-contact-evidence.zip` and `pathfinder-v6-tail-clearance.zip`, both pinned in `prepare_emerald_v7_reviewed_tools.py`. Five audited original Python source files are staged under new custody; all other ZIP contents, including the V6 asset, remain unextracted.
- Existing operator workspace on trusted storage with adequate free scratch space and enough memory for large skinned-array contact analysis.

## Operator command

From a source checkout containing the entire reviewed V7 stack:

```sh
python scripts/qualify_emerald_v7_offline_stack.py \
  --workspace /new/emerald-v7-qualification-workspace \
  --v7-bundles /verified/v7-zips \
  --v6-models /verified/v6-exact-models \
  --contact-archive /retained/source-and-contact-evidence.zip \
  --v6-source-archive /retained/pathfinder-v6-tail-clearance.zip \
  --budget-per-stage-seconds 1200
```

A completed original GLB is streamed from exactly four SHA-pinned ZIP parts into a new private model path with incremental full SHA-256 verification, never by arbitrary ZIP extraction. The independent V6→V7 verifier then checks **one** `orbit-02` tail-root correction of **160** keys and unchanged original mesh, rig, materials, other clips and growth.

The source-bound model is passed to the actual crossfade operator for **nine** phases × **six** transition directions. The interpreter must confirm 54 distinct source poses per stage. Results are checked against the recorded exact original V7 measured near-margin matrix. Any newly observed independent contact, missing pose, changed contact count, false GPU/art claim, changed underlying byte or time-budget failure refuses final completion and preserves diagnostic partial reports.

### Recovery

If an original 54-pose scan stops after some completed steps, a source-locked checkpoint holds the exact already-measured prefix. Re-run the same command with `--resume`. Both original V7 GLB staged bytes, both original V6 GLB source pins, two original source ZIP digests and all five staged contact tool SHA hashes are revalidated. A prior completed per-stage report can be reused only after its complete source-bound 54-pose content is independently checked again. A final `qualification-complete.json` is written exclusively when **both complete original models** and both 54-pose screens match all source evidence. An existing final receipt prevents unreviewed overwriting.

The final receipt states which actual model bytes, five reviewed tools, two structural verifications and 108 sampled poses were checked. It never grants continuous-time safety, unchecked anatomical pairs, arbitrary active-loop playheads, the real Three.js mixer, optional equipment, artist review, physical Unreal/RTX, remote GitHub binary upload, merge or release. The only numbers accepted from the ledger are **108 sampled poses**, **zero newly detected contacts in the three screened pairs**, **415,154 8-mm near-margin pair occurrences** and **59,508 inherited attachment-seam occurrences**; no safety conclusion is extrapolated to any unmeasured motion.

## CI and native acceptance boundaries

Source-only CI runs hostile fixtures and a synthetic orchestration test (marked explicitly synthetic); it **does not** run 229.5 MB original models. Full machine reports are created by the operator script only when provided with real original bytes, enough disk, and the reviewed source archives. The resulting evidence may be attached to a fresh draft PR but does not substitute for physical Unreal/RTX tests, independent device artifacts, release provenance, or repository merge rules.

**Strict holds:** 171,165 mixed-skin anatomical-risk triangles, other collision cohorts, true continuous skinned swept bounds, interrupted/repeated browser fades, poster fidelity, human-authored textures, inherited adult details, off-repo original binary publication and all final-head review/release gates. No automatic V7 adoption and no merge or release.
