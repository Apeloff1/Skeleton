# Game Builder — Physically witnessed incidents and causal NPC quests
**Authored:** 2026-10-12, Europe/Oslo. Stacked on physics-native encounter PR #3674 and its prior game-builder dependencies.

## Original event mechanics
An externally observed physical contact cannot, by itself, award a quest or NPC testimony. The witnessed bridge first independently replays a signed original Platformer, Racing or Sandbox source, then independently executes its source-derived physics rehearsal. Only actual physical fixture events (not wall collisions, client booleans or imagined damage) are eligible.

Because the current Physics reference does not record fixture IDs per contact, automatic site attribution is permitted only with exactly one solid source object and a matching explicit original-object-to-site author binding. Multiple potentially responsible colliders fail closed; a genuine avoided obstacle causes no incident at all.

For an attributable contact, the external physics event enters the canonical living-world director at the author's signed site: site integrity decreases by a finite severity, a new causal event is recorded with the real original editor/object and physics receipt digest, and the quest director independently determines line of sight, night/day visibility, testimony and direct witness memories. Obstructed NPCs never gain a fictitious eyewitness memory. A rumor remains a rumor rather than an eyewitness. The event is attributed to external physics, **not to the player**; the player earns no free reputation or rewards.

The resulting report includes original scene/session/physics/quest-scene digests, event identity, real witnesses, true source-born quest IDs, authored world timeline, final NPC/world state and deterministic SHA-256 evidence. Independent verification reconstructs both physical and quest worlds, denying modified NPC memories, forged damage, relocated colliders or fake quests.

## Gameplay
A finite follow-up action transcript can move the real player, inspect, interview witnesses, commit a branch choice, perform material followups, and conclude an ordinary authored quest. The world engine, not a separate ad hoc simulation, enforces site adjacency, witness credibility, material evidence, finite stocks and actual world consequences.

## Bounds
No implicit mutation of the original source game or its save, no unsupported attribution from multiple collided objects, no commercial-native certification or automatic learning-weight promotion. External incident mutation is an internal trusted primitive called only after verified physical source and explicit author binding.

## Regression
Ten new tests cover actual original racing impact/avoidance, source site damage and direct eyewitness generation, blocked sight, no free player reputation, real temporal world continuation, invalid author attribution, multi-object ambiguity, forged NPC testimony/damage, tampered original scene and finite action budgets. Added to the complete Windows/Ubuntu advanced-engine workflow.
