# Jeeves installed cognition integration — October 13, 2026

Three real typed endpoints execute the **existing** installed source:
\`skeleton.intelligence.uncertainty\` and
\`skeleton.intelligence.strategy_registry\`. There is no substitute
transformer, duplicate policy engine, provider call or shell execution.

\`ai.cognition.uncertainty\` accepts up to 16 bounded original answer/confidence
candidates and calculates a deterministic answer/abstain/escalate verdict.
The uncertainty explanation labels raw self-confidence as confidence,
never a calibrated probability.

\`ai.cognition.strategy\` constructs a real versioned
\`ReasoningPolicy\`, 1–16 bounded \`StrategyCandidate\` records and invokes
canonical risk-based, token/cost/time-aware \`select_strategy\`. High/critical
risk requires a strategy *capable* of verification; this is not itself
proof that external verification occurred.

\`ai.cognition.stop\` builds up to 64 actual \`ReasoningStep\` source records
and invokes canonical \`evaluate_stopping\`. A user's boolean
\`verification_passed\` is ignored and set false because no independent
verification authority was read here; a high-risk task cannot self-certify.

Game Studio includes distinct, interactive buttons for the three actions,
sample typed inputs, risk selection and full output receipts.

These are genuine operations of the installed cognition/uncertainty runtime,
not hardcoded fake scores. They advance functional integration around
VOL-013/VOL-248/VOL-253 but do not prove enterprise qualification,
trained-model skill or passed regression tests.
