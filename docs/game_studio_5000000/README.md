# Forge Studio — Five million executable operations and 1,000 technical books

This collection extends the [100 prior domain/director manuals](../game_studio_500000/README.md) with **900 source-grounded domain × director × finishing-pass technical volumes**. All ten finishing algorithms modify actual game source, appending tile geometry and a typed RPG event page, with actor/quest refinements only when newly produced. Their 4.5 million named workflows are **combinations**, not independent engines or complete games.

## Operation and documentation counts

| Feature | Count |
|---|---:|
| Existing source tools and compositions | 500,000 |
| New final-production composed workflows | 4,500,000 |
| **Total executable authoring contracts** | **5,000,000** |
| Previous technical volumes | 100 |
| New technical volumes | 900 |
| **Total technical volumes** | **1,000** |

## Source and release boundaries

The existing immutable `StudioProject`, tenant-scoped authenticated project revisions, native quest/NPC bindings, RPG sensor evaluator and Godot exporter remain the sole owners. The new `FinalProductionActions` registry is virtual-indexed rather than a list of millions of names. Server-side search is bounded to 64 records. Game sensor pages propose effects and **do not** certify executed combat, commerce, collision or device playback. Exact-head CI, native playthrough, security and IP review remain mandatory for merge.
