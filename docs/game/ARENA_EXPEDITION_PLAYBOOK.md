# Portable expedition playbooks

The combat-expedition-playbook CLI connects authored tactical combat, deterministic save/replay, earned inventory/currency, the bounded expedition solver, and portable bundle export. demo builds the original Lantern Harbor earned victory. build accepts --source-json and --actions-json; solve accepts --source-json and requires a replay-proven solver victory; resume accepts --session-json and --actions-json. verify accepts --playbook-json and reconstructs the initial checkpoint, route, final game state, economy audit, and portable bundle. A valid checksum is not authorization or a signature. Unknown fields, invalid source lineage, forged rewards, truncated solver results, nonterminal play and oversized artifacts fail closed. No network or model provider is required.
