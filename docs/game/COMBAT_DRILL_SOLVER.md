# Combat drill shortest-witness solver

`python -m skeleton combat-drill-solve demo` runs a bounded, offline,
deterministic breadth-first search over **actual** playable combat drill
actions. It never executes authored scripts, trusts submitted grades or
simulates imaginary combat rules. Every candidate invokes the canonical
turn engine, with opponent turns generated by the versioned tactical policy.

```bash
python -m skeleton combat-drill-solve demo
python -m skeleton combat-drill-solve solve --source-json '<drill-source>'
python -m skeleton combat-drill-solve solve --session-json '<saved-drill>'
python -m skeleton combat-drill-solve verify --result-json '<solver-result>'
```

The solver returns the shortest discovered legal player action list,
the original verified checkpoint, a full replayable terminal checkpoint,
search parameters, state count, source digest and a checksum receipt.
A resume search starts at the verified current state and returns only
remaining player actions. Already successful terminal checkpoints require
zero further actions.

At most 2,048 states and eight additional player actions may be explored.
The default is 512 states and eight player actions. Search is deterministic:
attacks are ordered by target identity, followed by guard and rest. A
`not_found_within_depth` result is not proof of unwinnability.
`budget_exhausted` means the frontier was truncated. Neither status
fabricates a terminal victory. Report JSON is capped at 2 MiB.

Verification replays the original drill, reruns the bounded search and
checks the complete result, including every opponent action, final grade
and receipt. Hashes prove consistency, not authorship or authorization.
Device and full exact-head CI qualification remain separate.
