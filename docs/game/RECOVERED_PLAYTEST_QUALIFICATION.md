# Recovered playtest, reference art, and scene byte qualification

Three installed source workflows compose existing archive owners rather
than replace them. quest-playtest-analytics executes actual synthesized
quest action prefixes with generated synthetic actors. Completed, failed
and truncated journeys produce canonical analytics events, use the
existing opt-out collector, and calculate funnel/stage difficulty cohort
metrics. Output is aggregate-only; the scenario identities are synthetic,
times are action-count proxies, and no retention or human playtest result
is asserted. Cohort floors and suffix suppression do not certify anonymity.

studio-frame-qualification uses supplied bounded RGB and binary subject
masks, an independently retained palette digest, and the existing GF-I
reference detector. It measures adjacent mask/colour discontinuities under
operator thresholds; the archival design bible and production template
owners produce follow-up guidance. It cannot authenticate capture origin,
evaluate physical wing deformation, render pixels, or certify AAA animation.
Source thresholds do not replace renderer or art-director approval.

scene-byte-qualification runs a source-pinned scene to an explicit end
state, reconstructs the canonical portable bytes at checkpoint intervals,
and compares the final state with uninterrupted execution. Bounded byte
and checkpoint budgets apply. These are in-process source replay checks,
not process restart, native engine/device or release evidence.

All CLI orders require independent input SHA and explicit authorization.
A missing-memory pressure observation now also resets the resource gate's
recovery streak; absent memory cannot be banked as healthy admission credit.
Canonical test selection is additive; test execution is not claimed.
