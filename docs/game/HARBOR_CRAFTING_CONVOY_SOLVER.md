# Convoy source-to-victory solver

The bounded convoy planner is an executable game-acceptance proof, not a synthetic victory record. `python -m scripts.game.harbor_crafting convoy-solve` validates the original Lantern Quay world and convoy board, obtains craftable weapons through real finite-resource transitions, plans collision-safe movement with the merchant patrol, escorts the convoy through every authored waypoint, resolves each real tactical encounter, and exports the exact action history plus the full replay-verified portable save. `convoy-verify-plan --convoy-plan plan.json` independently reruns the solver and compares all source, route, tactical and canonical state transitions.

The planner uses time-expanded bounded pathfinding (maximum 4,096 states per navigation) and rejects unreachable, uncraftable, oversized, lethal or otherwise unsatisfiable authored boards rather than fabricating completion. Every move, craft, escort and strike is checked by the same gameplay engine used by the terminal player. `pytest -q skeleton/testing/test_harbor_crafting_convoy_solver.py` covers earned victories, real weapon scarcity, tamper resistance and CLI integration. Focused tests and exact-head release gates must be executed before qualification.
