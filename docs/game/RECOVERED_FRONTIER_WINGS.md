# Recovered articulated membrane reference
Connects the existing rig, mesh, presentation clock and topology-aware
skin solver to a three-dimensional authored symmetric wing. Shared radial
seams avoid duplicated geometry. Proximal flapping is coupled to delayed
distal stroke, sweep, twist and continuous quintic glide transitions.
Moving anchors drive the original elastic solver; pin, floor, strain,
degenerate triangle and displacement defects are retained explicitly.

Orders support up to 10,000 source frames subject to independent vertex,
edge, phase and checkpoint limits. This is intentionally a CPU candidate
reference, not aerodynamics, native FEM, GPU rendering, or an AAA asset.
No physical wings, native animation quality, or release evidence is asserted.
Original yaw-only animation remains available; new explicit anchors are
optional. Canonical and AI mirror skin sources are byte-identical.
