# Replay-derived player guidance

The playable terminal accepts `hint` to show legal actions available **now**.
It does not promise an optimal route, guarantee eventual victory or modify the
player's save. Hints are generated by trying bounded candidate actions through
the canonical movement, NPC collision, inventory, crafting, trade and choice
engine. A legal move is only displayed if the actual transition succeeds.

For editor and CLI integrations:

    python -m scripts.game.harbor_crafting legal-actions --bundle checkpoint.json > hints.json
    python -m scripts.game.harbor_crafting verify-legal-actions --report hints.json

The portable report embeds a replay-verified source-bound save and the exact
resulting state digests for each action. Verifiers reconstruct every candidate
rather than trusting a supplied list or outer digest. Earned choices only appear
after dock delivery, completed campaigns have no available actions, and the
normal game tick, currency, inventory and NPC guards remain authoritative.
