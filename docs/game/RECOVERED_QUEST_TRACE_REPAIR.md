# B038/B039 recovered quest trace repair

The installed quest-trace-repair operation composes the archived B039
repair loop, B038 provenance ledger and recovered location-gated quest
runtime. Its sole deterministic proposer builds a bounded route from the
current canonical world location to the next active objective, including
required NPC interaction. It can discard an invalid action suffix but
does not rewrite world topology, mechanics, policy, reward definitions
or an explicit terminal abandonment. Actual gameplay replay evaluates
each candidate. Candidate eligibility requires a completed independently
reconstructed canonical action journal under the original plan pin.

The operator controls mutation count, time and per-mutation route size.
The finite action/candidate limits are enforced synchronously; elapsed
time is observed and late results are held, not forcibly interrupted.
Legacy 16-character B039 evidence remains in its original type, while
the integration binds full SHA-256 candidate observations, input and
final artifact identities into the B038 record. All reports are for
review; no model/provider, native engine, repository mutation, automatic
publication or release is authorized. This is a real deterministic
repair adapter, not learned model-directed repair. Qualification tests
are added to the existing gate; execution is still outstanding.
