# Authored mission end-to-end acceptance

Run python -m skeleton scene-mission-accept --demo --ending-id lantern_restored to verify an original playable mission ending. The command searches only legal canonical scene and mission actions, replays the route, exports/imports a portable save, and checks the actual reputation, choices and quest consequences. Without --ending-id it evaluates every authored ending. A result is accepted only when every requested ending has a verified playable witness. Exhausted state/depth budgets are inconclusive, not proofs of impossibility. --verify-json accepts a prior receipt and recomputes the full evidence from the source or verified checkpoint; checksums are not signatures. --source-json or --session-json selects the source. Search and output are bounded, and no external model or network is required.
