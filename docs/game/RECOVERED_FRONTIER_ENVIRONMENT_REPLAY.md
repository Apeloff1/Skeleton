# Recovered coupled frontier environment replay

An installed deterministic CPU-reference workflow executes the existing
presentation clock, atmosphere, microclimate, climbing/traction,
body-balance, biome motion, leaf dynamics/shadow verification and
volumetric photometry owners in a common frame loop. Wet/ice conditions
modify traction and support friction; pressure-modified wind moves
shrubs, rocks and leaf attachments; actual moved geometry feeds the
existing shadow and atmospheric ray solvers. The same scene is executed
twice, compared frame-chain by frame-chain via its digest receipts, and
reported with numeric extrema, explicit defects and sampled checkpoints.

Admission bounds orders to 10,000 frames per pass, 256 checkpoints,
five million estimated ray-intersection work units, one million estimated
motion object steps and closed typed scene inputs. This is intentionally
a CPU reference, not Blender/Unreal execution. It produces no rendered
frames, physical device evidence, verified 3D assets, model claims,
FEM or GPU ray tracing certification. Balance and traction evaluate the
specified stance, not a native animated character. Invariant failures
are retained and never silently converted to successful qualification.
Source regressions are selected; actual execution is pending.
