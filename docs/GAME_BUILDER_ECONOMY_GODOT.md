# Original Economy — Independent Godot 4 Native Milestone

Date: 2026-10-12 (UTC date). Source: dependent on advanced Economy PR #3668.

## Executable upgrade

Adds a separate Godot 4 Control scene with real and independently implemented
market state transitions, rather than a viewer of Python outcome screenshots.
Reference Python receipts supply only a **comparison target** for the exported
Godot verification mode.

Game controls include physical neighbor travel, focus on up to eight goods,
finite paid buying and selling, manufacturing, harvesting, market auditing,
rest and household relief, claiming actual trade cooperation and optional
retirement. A real game canvas displays each market's stock and ask price,
treasury, player cash, inventory, production, trade and household sales.

The native replay proves the **entire game-state dictionary**, including:
market inventories, prices, labor resources, household money, treasuries,
cargo origin per unit, consumer activity, transported units, audited markets,
milestone and optional ending. It runs original Godot rules from approved
source settings, scene and actions. No Python runtime executes inside Godot.

`godot --headless --path godot -- --verify-economy`

Godot process has executed** with the authored proof and exited successfully.
