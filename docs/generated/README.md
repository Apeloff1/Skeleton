# Generated documentation boundary

Files under this directory are derived outputs. Generated sections must be
identified by Skeleton ownership markers and bound to a generator identity plus
a deterministic source-digest set.

Human rationale, warnings, operational caveats, and legal interpretation must
remain outside generated ownership markers. The generator must replace only an
existing uniquely bounded generated section; missing, duplicate, or malformed
markers fail closed instead of causing an append or overwrite.

Derived outputs are regenerated from authoritative sources rather than edited
by hand. Review uses the generated manifest digest to distinguish source or
generator changes from manual drift.
