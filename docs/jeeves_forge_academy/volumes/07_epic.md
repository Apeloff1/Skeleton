# Jeeves Academy Volume 07 — Cross-region high-scale layered world orchestration

**Curriculum generation:** `epic` · **Authority:** canonical game-learning project and Forge Studio source controller · **Provider training:** not performed · **Source references:** indexed `forgebook:epic:0` through the true final index of this generation.

## Educational intention and competency contract

Saga prerequisite plus epic multidisciplinary production. Compose continental, sky, ocean, metropolis, maze, ecosystem, siege, dimension, dynasty and finale source regions. This is an original-game production curriculum, not a generic AI encyclopedia. Every book in this generation is addressed by a stable source reference `forgebook:epic:<index>`, resolved to a real source-generated manuscript only when needed, and linked to its preceding generation with deterministic integer rank. No bulk allocation, implied acquisition of copyrighted ROMs, unearned AI weight promotion, or fake autonomous completions are permitted.

## Mandatory reference study and concrete skill exercises

1. **Inspect your owned game.** Obtain authenticated project revision and canonical source checksum; ensure the exact world/game content is present, rather than assume a demonstration scene.
2. **Resolve a registered source book.** Select a generation and integer index, fetch its permanent reference, parent chain and exact technical source-producer operation. Reject unknown, out-of-range, padded or path-like input.
3. **Materialize the lesson.** Render precisely the selected original Markdown book and verify byte-count and SHA-256 integrity; compare its registered archetype commands and gameplay workups to the source registry.
4. **Read and reason.** Document GDD intentions, world architecture, character history, quest mission conditions, environment observation dependencies and the inherited earlier-generation canon.
5. **Theory assessment.** Answer each exact book-axis question using the source terms actually addressed by the book. A passing result is a structural comprehension receipt; it does not prove neural training, creativity or native game skill.
6. **Plan original-world authoring.** Ask Jeeves to propose the *exact registered* source action from the selected book. Validate that its configured game region, palette, layer and prefab inputs are valid in the current source revision.
7. **Preview a real transaction.** Run the actual canonical immutable Forge batch against current project source. Compare hashes, look at concrete tile edits, optional story elements and any evidence-gated RPG pages; do not save yet.
8. **Challenge the preview.** Scrutinize new-only actor/quest modifications, reachable alternate routes, rights, GDD continuity, any missing native environment observations and failing examples.
9. **Operator authorization.** Only the project owner/editor may explicitly approve the exact preview hash with matching version and current source; a stale or different candidate is rejected.
10. **Native qualification.** Compile the saved Godot project in the actual toolchain, inspect controller routes, savegame, frame and environment evidence; do not infer playability from authored source.
11. **Learning evidence.** Record the separate theory score, source digest, preview candidate digest, verification results, native outcome and copyright disposition as scoped evidence. Training weights remain unchanged until a real model-training owner runs and signs a separate training job.
12. **Apply corrections.** Revisit the source book by exact immutable reference, correct the real project, and repeat verification. A denied edit is a reproducible failure state, not an excuse to lower standards.

## Specialized studio practice

Author up to eight explicitly selected original map layers; preserve palette and center-spine traversal; generate native-proposed event. Use genuine original-game assets and own creative scene prose. The gameplay and physics engine may return proposals rather than events that have actually executed; validate that separation. Avoid presenting vast virtual source combinations as distinct engines or finished worlds. Support windows-long and months-long project histories by binding each chapter or stage to the authoritative source receipt.

## Evaluation matrix — twelve independent safeguards

1. Exact project/tenant and source revision.
2. Authenticated source-book identity and parent path.
3. Source operation exact registered membership.
4. Host-owned authoring preview and project digest.
5. Story/canon continuity and original voice.
6. Route accessibility and negative path testing.
7. Native gameplay observed predicates and proposed outcomes.
8. Provider boundaries and no unconsented SDK/model calls.
9. Recoverability, idempotency and CAS revision.
10. Independent reviewers and objective comparative baseline.
11. Copyright/creative rewriting as final review.
12. Actual work evidence stored by an authorized host, not claimed through logs.

## Measurable acceptance and grade integrity

**Specific evaluation:** Validate worldline/campaign/chronicle/epoch/saga canon, multi-route travel, real Godot export and measured hardware path. Measure exact-axis theory, actual source diff and repeatability, game route and quest-graph legality, compare measured native performance only when actually run, and isolate rights and originality checks. Promote only after native compiled game, controller playthrough, full rights scrutiny and hash-linked peer reviews. Two independent verifiers and an adversarial reviewer should scrutinize gaps; release decisions require separate human/legal authority.

## Failure analysis and recovery

A learner may encounter a missing source revision, stale CAS, mismatched prerequisite hash, unregistered book, corrupt ZIP, forged operation name, excessively large rendering request, unobserved physics sensor, route softlock or unowned game. Stop the attempted edit and retain the last verified project. Refresh the host-owned source, choose a valid indexed book, return a typed bounded error and retry after the actual underlying condition has been corrected. Never auto-retry arbitrary unsafe mutations.
