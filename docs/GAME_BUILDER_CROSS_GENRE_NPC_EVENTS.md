# Cross-genre original game achievements → witnessed NPC world consequences
**Timestamp:** 2026-10-12, Europe/Oslo. Stacked on conditional NPC game-world PR #3693, portable saves #3691, source-authorized eyewitness world #3685 and original Game Builder engines.

## Game creation capability
An authored farming, sailing or flight game can now transfer a **genuinely achieved source event**, not just an event label, into an original 49-cell NPC world. Exact authenticated gameplay session, signed original authored scene and settings, action-index receipt, complete source event trace and gameplay-specific terminal/resource state are all checked before the transfer.

The three initial reviewed adapters are: (1) an original farm `harvest:<plot>` that actually harvested a mature crop, producing a local discovery story; (2) original maritime `dock` that physically reached the port, passed navigational markers and delivered finite cargo, contributing at most one actual stocked unit to a chosen authored NPC site; and (3) an original aircraft `land` action after genuine approach/navigation, producing a source-backed discovery. Non-terminal docking refusals, unripe crops, synthetic source event names, unsatisfied airfield conditions and absent signed source game scenes cannot cross the boundary.

## Exact causality and NPC mechanics
Each original action index is unique, bounded and mapped explicitly to an existing original NPC site. The bridge independently replays the entire source genre game and validates the exact ordered action transcript before applying any event. A deterministic origin receipt carries source session digest, genre, actual event code and original action index. Events are applied to one persistent canonical quest world through its existing NPC line-of-sight, trust, evidence, rumor and causal quest machinery, not a new self-declared testimony generator.

Genre events use `actor=external:genre`: they do not pretend the player physically performed NPC-world repair/harm, cannot count as a player's material choice and do not provide free reputation or gold. Only a genuinely delivered maritime cargo can increment bounded world-site stock. Farm harvesting and aircraft landings can create knowledge/quest leads but not cargo. NPCs behind obstacles cannot become omniscient direct witnesses. Original time, finite event capacity, source scene and source action trace hashes remain auditably replayable.

## Studio
The original local game Studio offers **Inspect earned original source events**, an authenticated original-action index selector, NPC site choice and **Replay original achievement into NPC world**. Creators can inspect complete verified source evidence, the actual eyewitness/rumor memories, attributed causal quests, physically bounded site stock and a final digest. Server reconstructs both the original genre game and independent NPC world before returning accepted results.

## Tests and CI
Eight new adversarial engine tests exercise real harvest, real completed maritime delivery, safe aircraft landing, denied unripe/refused events, authentic NPC followups, source-index uniqueness, forged event/source/NPC/stock attacks and malformed source errors. Three Studio tests check the actual controls and independent source replay route. Full Windows/Ubuntu advanced reference CI now includes both the bridge and visual Studio regressions.

## Security and release boundaries
The initial bridge starts a distinct original NPC-world investigation. This is not yet automatic incorporation into the existing persisted six-episode physical campaign or a full native cross-engine Godot runtime. It executes only server-side typed canonical source gameplay; no user Python code or arbitrary script is imported. SHA-256 digests provide deterministic reproducibility, not private-key signature authenticity. The original game files and saved projects are not automatically modified, and native hardware certification, publishing and AI weight promotion remain explicitly disabled.
