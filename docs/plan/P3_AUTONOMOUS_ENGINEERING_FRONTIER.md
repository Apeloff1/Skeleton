# P3 Autonomous Engineering Frontier

P3 starts from the exact 257-volume queue preserved by the P2 Functional-AI
closure. It does not reinterpret the 57-volume P2 landed frontier and it does
not erase the remaining masterplan breadth.

- source frontier: **257** volumes

## Dependency spine

`P3-AUTH-01` freezes scope and ownership.

`P3-WORKFLOW-01` materializes workflow IR/DSL/compiler/versioning,
semantic task typing, decomposition, critical paths, scheduling and simulation.

`P3-AUTONOMY-01` adds bounded autonomy control and escalation.

`P3-CHANGE-01` binds project/workspace identity, artifact dependencies,
impact analysis, risk estimation and safe-change planning.

`P3-TOOLS-01` adds plan analysis/simulation plus trusted tool discovery,
health, dependency, composition and result-trust gates.

`P3-EFFECTS-01` makes side effects durable and compensable through a ledger,
compensation engine and saga state machine.

`P3-AGENT-01` is the terminal bounded frontier for an autonomous engineering
worker, multi-agent engineering, controlled self-improvement, performance/cost
evidence, disagreement handling and autonomous-worker acceptance.

## Authority boundary

A landed implementation remains `landed_unpromoted` until independent
accountability and verification authority promote it. No percentage, file
presence, branch status, provider availability or test name can substitute for
executable evidence.
