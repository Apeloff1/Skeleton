# P3-T2 Acceptance

The T2 acceptance gate executes one provider-independent chain:

1. content-addressed, rights-bound dataset ingestion;
2. deterministic local training with shard plan and checkpoint;
3. elastic checkpoint recovery;
4. independent training metric gates and isolated post-training receipt;
5. bounded reinforcement-learning episode and curriculum gate;
6. independently evaluated verifier-model candidate;
7. multimodal document ingestion and provenance-preserving retrieval.

Hosted model credentials are explicitly cleared in the workflow. The fixture is a
bounded functional proof, not a claim that the portable reference trainer is a
production-quality frontier model.

The T2 closure may only cite this gate after it succeeds on an exact
implementation head.
