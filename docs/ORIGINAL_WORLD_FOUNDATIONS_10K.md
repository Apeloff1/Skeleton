# 11,536 original-world foundation entries — authorial provenance and playable rules

**Status:** Experimental, offline game-design and causal-execution prototype.
Integrated in the Skeleton game generation package on PR #3641.
This is not a claim that eleven thousand independently hand-written stories,
native console binaries or commercially finished games have shipped.

## What was added in this expansion

| Foundation category | Count | Authorship status |
| --- | ---: | --- |
| Existing individually written original worlds | 1,296 | Each individually written in prior atlas |
| New individually written **root world laws** | 128 | Every premise, player lever, failure condition and continuity policy separately written |
| New individually written **regime laws** | 80 | Each narrative and causal constraint separately written; ten distinct executable operator families |
| Newly written **root-domain × regime-family bridges** | 160 | Each interaction clause separately written |
| Exact-addressed composed causal world foundations | 10,240 | Generated by crossing 128 roots with 80 regimes and selecting the corresponding authored bridge; **not individually written prose entries** |
| Aggregate atlas world-foundation entries | **11,536** | 1,296 existing bespoke plus 10,240 structured new entries |
| Individually authored world-root premises across the atlas | **1,424** | 1,296 previous worlds plus 128 new bespoke root premises |

The **10,240** foundation compositions combine authored laws that actually
interact. They are not 10,240 visual skins, era tags, generic seeds or
different random numbers. The same underlying laws can produce distinct
causal consequences when their operator, source domain and intensity vary.
The generator does **not** claim 10,240 separately hand-written or fully
adapted source worlds.

The editorial authoring files are:

- `original_foundation_roots_a.py` and `original_foundation_roots_b.py`:
  eight original laws in each of sixteen systemic disciplines:
  geometry, chronology, ecology, materials, governance, communities,
  commerce, memory, language, theology/metaphysics, navigation, discovery,
  machine agency, crafts, relationships and survival
- `original_foundation_regimes.py`: 80 original follow-on regimes,
  8 each in echo, public levy, reversal, threshold, migration, veto,
  cascade, material exchange, finite auction and branching histories
- `original_foundation_couplings.py`: 160 individually written
  interaction claims, one for each of 16 disciplines crossed with 10
  operator classes; these describe the consequences of connecting the
  root-world invariant and the regime
- `original_foundation_compiler.py`: immutable typed models, validation,
  provenance receipts, deterministic hashes, exact ranking, bounded
  pagination, root/regime lookup and seed lookup without allocating
  an enormous universe

These disciplines and operators have **actual causal roles**, rather than
only cosmetic labels. The same geometry premise with an echo regime
produces delayed transit obligations; with a veto regime its changes are
subject to citizen assent; with migration its local route advantage
shifts to remote communities; with an auction it must spend finite survey
collateral. Different root-world premises have independently written
requirements and failure conditions.

## Distinct law vs. law realization

The cross-law compiler preserves the full text of each root invariant,
the overlay invariant and the authored coupling, and constructs a
unique `foundation_id` and `design_id`. Every foundation provides
`root_id`, `regime_id`, `domain`, `ending_policy`,
`secondary_ending_policy`, `player_lever`, `failure_pressure`,
`provenance` and an honest `implementation_status`.

`original_foundation_runtime.py` implements a shared deterministic
**generic causal reference game**, exposing each of the 10,240
compositions to actual game actions and receipts. It does not enact
every bespoke detail of all 128 fictional root premises; bespoke
adaptation is a separate requirement before a foundation may be
promoted as a complete game.

Executable actions:

- `intervene` activates the root-domain resource cost and the regime's
  own one-of-ten causal rule. Eight subtypes per root-domain have
  different effects, energy requirements and hazard intensities.
- `study`, `restore`, `negotiate` and `donate` build evidence,
  repay actual resource costs, establish credible consent and
  contribute to public reserves.
- `move`, `survey` and `build` change the connected twelve-sector
  network, reveal actual reachable sectors or build material-costed
  lasting outposts.
- `trade`, `salvage`, `rest` and `end_turn` operate finite communal
  stocks, stamina and delayed societal/environmental clocks.
- `choose care` / `choose power` establishes an irreversible local
  policy fork with distinct social/hazard consequences.

Causal operators are stateful, not placeholders:

| Operator | Actual reference-game state consequence |
| --- | --- |
| Echo | Queue a delayed effect and repayment duty for subsequent turns |
| Levy | Transfer available player resources into a public communal reserve |
| Reverse | Alternate positive progress with partial reversals and remote consequences |
| Threshold | Unlock a distinct milestone once progress clears a level-specific gate |
| Migration | Transfer local benefit into another area's continuing account |
| Veto | Reject action when legitimacy falls below a declared floor |
| Cascade | Compound effects with risk and liability, bounded by explicit caps |
| Exchange | Debit finite commons reserves in exchange for player supplies |
| Auction | Transfer a resource-backed bid to public escrow |
| Fork | Commit to a persistent care/power choice with different next effects |

The simulation enforces finite stamina, material costs, actual passage
adjacency, bounded reserves and hazard caps, action budgets and
tamper-evident deterministic event receipts. Save-game SHA-256 checksums
are **integrity checks, not secure signatures**.

Ending policies preserve deliberate noncompletion: an `unwinnable`
world cannot be marked complete even if the player amasses resources.
Persistent and postgame simulations can continue after a chapter milestone.
An editor can distinguish a world-law's own primary ending policy from
its regime's narrative continuation option.

## Browsing the catalog and playing it

```bash
# Exact figures with provenance counts: no counting artistic variations.
python -m skeleton.game.generation.original_foundation_cli --report

# Page through specifically authored-rule compositions.
python -m skeleton.game.generation.original_foundation_cli \
  --page 10000 --limit 20

# Select any exact legal foundation index [0,10239].
python -m skeleton.game.generation.original_foundation_cli \
  --index 10000 --interactive

# Exact-turn reproducible play with verifiable consequences.
python -m skeleton.game.generation.original_foundation_cli \
  --index 9999 \
  --actions-json '[{"verb":"intervene"},{"verb":"study"},{"verb":"end_turn"}]' \
  --show-map

# Durable signed-format-by-checksum game-state envelope.
python -m skeleton.game.generation.original_foundation_cli \
  --index 1999 --save my-foundation.json \
  --actions-json '[{"verb":"intervene"},{"verb":"end_turn"}]'

python -m skeleton.game.generation.original_foundation_cli \
  --load my-foundation.json --interactive --save my-foundation.json

# Existing atlas entrypoint can also preview the extended corpus.
python -m skeleton.game.generation.original_world_cli \
  --foundation-index 10239 --brief

python -m skeleton.game.generation.original_world_cli \
  --foundation-seed original-creative-vision --brief
```

The original `original_world_cli --index` and
`original_world_compiler.blueprint_at` continue to address the
prior 1,296 individually authored worlds without renumbering the
legacy machine-facing recipe space. These APIs are deliberately
backward compatible. The new corpus uses a separate
`original-foundation-atlas.v1` identifier to avoid ambiguous
world indexing.

## Quality gates

New checks assert:

1. Exactly 128 separate root laws and distinct titles/invariants,
   80 original overlays and 160 unique authored couplings.
2. All 10,240 composed foundations have distinct identities, titles,
   causal signatures and nonempty interaction statements; no visual
   style or console target is counted as a new foundation.
3. Every foundation can initialize and execute a bounded turn with
   a stable event receipt; all 160 domain/operator pairs can run a
   real intervention.
4. Eight independently authored core variants in one discipline
   produce measurably different costs and outcomes; overlays have
   distinct intensities and operator families.
5. Replay, hash-chained state transitions, save/resume, pagination,
   physical cost accounting, legal route connectivity, persistent
   branching and deliberately unfinishable worlds have regressions.
6. The existing 1,296-world atlas, eight prototype rule kernels and
   game runtime continue to pass their earlier suite.

The dedicated `Original World Atlas` workflow compiles game-generation
modules, runs all focused tests, exercises interactive-ready CLIs in
batch mode and checks the exact commit SHA. Because unrelated
repository authority workflows currently have failures, this PR is
**draft / not approved for merge** despite independently successful
game tests when confirmed.

## Next realization stages

The remaining work to reach the full vision is extensive:
bespoke root-law executors beyond the shared reference kernel;
dynamic authored quests and diverging postgame societies for each
foundation; authored planetary/labyrinth/voxel/indoor/underwater/
interstellar topology adapters; native render and platform
compilation; animation, sound and accessible UX; evidence-based
novelty and IP safety review; automated playtesting, performance
budgets and curated promotion from abstract proof to playable game.

A large indexed set is useful to the Dragon builder only if it can
pick foundations by actual causal need and convert those chosen
foundations into rigorously tested native deliverables. A huge number
alone is not proof of that last mile.
