# Offline archive custody repair
Web and native staging now consume a private snapshot whose exact bytes are hashed during copy, not an archive path opened after a separate digest check. Native staging verifies the full model through the original admission parser and records an extracted-file hash inventory. Explicit archive directory entries are accepted only when safe; Windows reserved names and case-folded duplicates are denied. No archive content executes. All staging is in trusted, operator-controlled local destinations; no protection is claimed against an attacker with concurrent write access to those directories or filesystem administrators. The synthetic native archive regression checks the data flow, not playable content. Existing size quotas are retained until the actual pinned pack can be inspected.
