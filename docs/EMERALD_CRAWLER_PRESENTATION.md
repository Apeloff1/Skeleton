# Emerald crawler presentation
The existing authenticated crawler workspace owns the data. Emerald consumes a derived, bounded event projection. Browser mode uses the existing authored leather solver (WebGL2 with its software path), side/launch/landing atlases, and ground deformation; actual row emphasis is constrained to the event target. No extension is injected and no external page is scraped. Static assets are exact-manifest-pinned and scripts use SRI. Reduced-motion and power-aware settings suppress animation; unavailability falls back to the legacy companion. This is not a physical RTX or Unreal renderer. The 2.9D flight presentation remains experimental pending visual signoff and real-device profiling. No capture event implies knowledge review or model training.
