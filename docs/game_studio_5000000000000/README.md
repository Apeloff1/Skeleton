# Forge Studio 5 trillion source compositions / 1 billion addressable game-production manuals

This tenfold extension preserves the previous 500,000,000,000 exact stable authoring IDs and adds 4,500,000,000,000 arithmetic `saga_*` identities. It **does not** assert 5 trillion independent games, distinct engines or native-playable titles.

## Authored code paths and single ownership

- `skeleton/forge/game_frontier_studio_saga_production.py` implements ten real topology maps, ten environment-gated gameplay proposal signatures, new-only actor staging and chapter quest-branch continuity; source edits transit the original immutable `StudioProject`.
- `skeleton/forge/game_frontier_studio_authoring.py` performs canonical exact-ID membership checks, source compilation, batch receipts and dispatch; `backend/core/game_frontier_authoring.py` maintains existing host-owned CAS/persistence.
- `backend/routes/game_frontier_authoring.py` exposes authenticated bounded recipe searches and exact handbook read/ranking, and `frontend/src/product/gameFrontierAuthoringClient.ts` plus Jeeves panels present the same contracts.
- `skeleton/forge/game_frontier_studio_saga_handbooks.py` has 900,000,000 deterministic on-demand book identities, taking the total addressable manual catalogue from 100 million to **1 billion**. They are not one billion files stored in Git.
- `scripts/export_game_studio_saga_handbooks.py` materializes a bounded batch of **1..100 actual Markdown files** plus byte-level SHA-256 receipts and separately ranked real-batch length/completeness.

## Ten implemented story/world production families

1. [homecoming](sagas/homecoming.md) — A two-route safe arrival network, narrative re-entry and hometown continuity.
2. [faction_concord](sagas/faction_concord.md) — A signed neutral crossing between hostile districts with faction reputation consequences.
3. [buried_history](sagas/buried_history.md) — A new archaeological ring circuit revealing historic landmarks without rewriting canon.
4. [skyward_migration](sagas/skyward_migration.md) — Aerial loops and grounded evacuation paths linking sky settlements.
5. [oceanic_reckoning](sagas/oceanic_reckoning.md) — A bounded coastal crossing with tide-gated access and inland recovery.
6. [citadel_reconstruction](sagas/citadel_reconstruction.md) — Rebuilt streets, civilian access and reversible post-conflict choices.
7. [wildlife_pact](sagas/wildlife_pact.md) — Seasonal habitat restoration with multiple migration and habitat crossings.
8. [betrayal_aftermath](sagas/betrayal_aftermath.md) — Two mutually legible confrontation routes and an opt-in reconciliation scene.
9. [starfall_observatory](sagas/starfall_observatory.md) — An observable astronomy scene and multiple pathways to a mountaintop observatory.
10. [branching_epilogue](sagas/branching_epilogue.md) — Three routes to a postgame hub with independent long-form consequence notes.

These ten manually curated construction dossiers document objective source mutations, sensor evidence, continuity and native qualification. The other 900M identifiers are **virtual on-demand** source-grounded books, not human-reviewed manuscripts.

## API / discovery

`GET /api/game-frontier-authoring/recipes?generation=saga&domain=realm&saga=homecoming&offset=0&limit=32`

Exact allowed filters: domain, system_layer, director, finish, worldline, phase, campaign, chronicle, epoch and saga. Generation never scans a 4.5T-item list; it reconstructs exact IDs with mixed-radix rank/unrank and bounded pagination (1..64).

`GET /api/game-frontier-authoring/saga-handbooks/{domain}/{treatment}/{director}/{worldline}/{phase}/{campaign}/{chronicle}/{epoch}/{saga}`

`GET /api/game-frontier-authoring/saga-handbooks/rank/{domain}/{treatment}/{director}/{worldline}/{phase}/{campaign}/{chronicle}/{epoch}?sort=quality`

`python -m scripts.export_game_studio_saga_handbooks --out build/forge-saga-books --offset 0 --limit 10`
