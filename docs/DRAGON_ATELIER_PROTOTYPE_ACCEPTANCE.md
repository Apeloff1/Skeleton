# Prototype acceptance and operator journey

The prototype deliberately targets the original full 3D Atelier Fold model, not prior generated posters or a surrogate mesh.

1. Obtain the original model and source archive from its creator; preserve exact bytes and independently conveyed SHA-256. Do not use a digest written by an untrusted importer.
2. Run the offline admission script and explicitly map real clip names to the four families. Keep the source archive separately. If the final model differs from the historical rig or library-size assumptions, reconcile the policy against the original model rather than padding the catalogue.
3. Sign into Skeleton, open an owned crawl in the ordinary workspace or first-install research pilot, then open the local 3D prototype panel. Choose the GLB, admission JSON and trusted digest. No files are uploaded. The existing companion and capture controls continue independently.
4. Verify ground, takeoff, extended flight and landing from actual recorded capture events. Verify revoked consent, error, cancellation, owner change, focus loss, visibility, reduced motion, and WebGL context loss. Movie/render assets are not proof of live playback.
5. Inspect all four actual clip families, crossfades, full-resolution generated geometry, folded-wing and limb clearance, membrane strain, skinning, lighting, shadows, loop continuity, and native texture provenance. Record exact model digest, head SHA, device, graphics driver, memory and frame-time distribution; no invented FPS.
6. Compile the original Unreal source separately from the browser and measure native physical RTX execution. This branch implements neither that compile nor a ray-tracing shader. Real-device, Windows/WSL2, native and security holds remain separate.

The exact-head workflow tests source and synthetic fixtures, TypeScript and Expo export. A pass does not establish any artistic, real-model, hardware or production release acceptance. Never merge or release on this evidence alone.
