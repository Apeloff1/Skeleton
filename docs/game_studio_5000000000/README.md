## One million available technical books

The previous library offers **100,000 volumes**, including physically committed original books and on-demand worldline/phase books. This edition adds **900,000 new on-demand campaign manuals** through `skeleton/forge/game_frontier_studio_campaign_handbooks.py`, bringing the **addressable catalog to 1,000,000**.

The new books are **reproducible generated Markdown, not 900,000 static files added to GitHub**. The catalog is a six-dimensional index:

- Ten game-production domains
- Nine source production treatments
- Ten directors
- Ten worldline systems
- Ten game phases
- Ten campaign families

That is 10 × 9 × 10 × 10 × 10 × 10 = 900,000 technical manuscripts. Each new book contains 50 original archetypes × ten gameplay systems × ten final production options, covering 5,000 exact source-editing commands. As a catalog, 900,000 × 5,000 = 4.5 billion **composed workflows**.

Every manual includes an exact command inventory, gameplay systems, typed environmental observations, original-world CAS production, native integration instructions and 30 adversarial/objective acceptance checks. Its SHA-256 receipt and word/character counts are computed from the **rendered manuscript**, not estimated from the metadata.

## Ranking: quality versus length

The requested comparative ranking is implemented through two *separate* modes:

| Rank mode | Exact ordering | Interpretation |
|---|---|---|
| **Quality-first** | Descending deterministic documentation-completeness score (0–100), descending measured word count, then stable campaign ID | Source/evidence completeness; **not** a measured game-quality score |
| **Length-first** | Descending measured word count, descending completeness, then stable campaign ID | Longest **actual rendered** manuscript, not more polished or more playable |

Quality checks include registered exact source references, 50 concrete archetypes, ten system examples, seven required construction sections, 30 review/qualification items, observed game-action boundaries, immutable source/CAS traceability, and native/IP signoff instructions. The rubric is inspectable and tested to **penalize missing required material without rewarding filler**.

**Ranking scope:** exact comparison of all **ten campaign variants for one selected domain/treatment/director/worldline/phase context**. It is not a misleading global top-one-million ranking. Ranking across exported batches is also supported, explicitly limited to the actual materialized batch.

### Authenticated game-learning API

```text
GET /api/game-frontier-authoring/recipes?generation=campaign&domain=realm&campaign=chapter_crossroads&limit=32
GET /api/game-frontier-authoring/campaign-handbooks?domain=realm&limit=32
GET /api/game-frontier-authoring/campaign-handbooks/realm/waterways/navigation_alternates/river_network/dawn_routes/chapter_crossroads
GET /api/game-frontier-authoring/campaign-handbooks/rank/realm/waterways/navigation_alternates/river_network/dawn_routes?sort=quality
GET /api/game-frontier-authoring/campaign-handbooks/rank/realm/waterways/navigation_alternates/river_network/dawn_routes?sort=length
```

The React Native Jeeves/Forge authoring panel provides selectable exact campaign operations, source-edit preview/commit, manual reading and user-facing **Rank quality / Rank length** controls.

### Materialize actual books with both rankings and SHA manifests

```sh
python -m scripts.export_game_studio_campaign_handbooks --out build/campaign-books --offset 0 --limit 25
```

The exporter writes actual `.md` files, 100-document-bounded source SHA receipt shards and a `campaign_ranking_0_25.json` file containing two rankings of **only those 25 generated books**. Use separate bounded batches for large productions; no global scan is performed.
