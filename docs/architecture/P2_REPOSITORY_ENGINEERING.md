## Executable policy hardening

The repository control plane now binds seven executable repo-machine controls into the machine authority: transactional edits, independent review, cross-language indexing, deletion governance, blocker-first priority, evidence-derived completion, and anti-pattern exception expiry.

Deletion is deny-by-default and requires all six canonical checks. Trace reachability is sourced from the landed master traceability graph and its implementation-path impact rule.

Completion cannot average away blockers. Failed gates, unresolved hard dependencies, and invalidated evidence identities remain non-compensable; changed implementation paths invalidate watched completion evidence until exact-head revalidation.

Anti-pattern exceptions default to deny. Any future waivable pattern must explicitly allow exceptions and bound their TTL; every exception must carry owner, rationale, timestamps, and evidence.
