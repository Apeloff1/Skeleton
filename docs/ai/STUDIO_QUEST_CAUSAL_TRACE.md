# Source-bound quest causal witness audit

This Studio A vertical explains why authored choices unlock or block specific
original endings. It never invents world evidence. A source lease and initial
session lease bind the exact authored quest and narrative documents.

Use the typed Jeeves tool `studio_original_quest_causal_witnesses` or
`python -m scripts.studio_quest_causal_trace_cli --project PROJECT
--expected-source SOURCE_SHA256 --expected-session SESSION_SHA256 --prompt`
to compile a deterministic predicate witness trace. The CLI also accepts a
private authored `--authoring-file` containing baseline/candidate actions.
`--html-preview` returns an escaped, script-free human-readable audit.
`--publish DIRECTORY` writes a no-clobber private receipt, and
`--restore DIRECTORY` reconstructs and replays the canonical consequence
receipt from the self-contained private causal receipt. A second file is not
required.
`--playable` requests a guarded sandbox handoff, not native game certification.

Every branch step is replayed from the canonical source; witness origins are
only completed stages, authored rewards, and explicitly declared choice effects.
Unmet external predicates stay unmet. The handoff is denied if either branch
lacks an authored eligible ending. No model-provided tool name is dynamically
imported; the static Jeeves router retains explicit operator authorization.

Run focused validation against the exact remote head:
`python -m pytest -q tests/test_studio_quest_causal_trace.py
tests/test_studio_quest_consequence_diff.py`.
Then require full exact-head CI and independent review. No release/device
qualification is implied by these source changes.

The same CLI can render a CSP-hashed offline edit surface with
`--prompt --editor-preview`. After editing actual stage/choice histories,
import its private source-leased JSON with `--editor-export PATH`. The
import replays both canonical branches before a causal witness audit and
optional guarded sandbox handoff. Browser exports do not grant authority.
