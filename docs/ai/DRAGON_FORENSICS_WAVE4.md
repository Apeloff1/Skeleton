# Dragon forensic research operations — wave four

Three more metadata-only, policy-bound Dragon forensic stages raise the
forensic assurance chain from seventeen to twenty stages. These are additive to
the original twenty-six-stage Dragon Atlas and never create autonomous crawl
authority or verified factual conclusions.

## Source usage reverse index
`compile_source_usage_map` links selected retained passage **hashes and
operator objective IDs only**, retaining the current mandate/snapshot and
current source policy fences through the enclosing verified Atlas. Exact
source identities cannot be counted as independent evidence more than once.

## Research gap synthesis
`synthesize_research_gaps` correlates:
- exact required/blocked objective-term coverage,
- host loss and potential source-family dependence,
- source provenance replay limitations,
- cross-objective source reuse and host concentration.

Every deficit is a reason-coded human research lead, never a discovered URL,
permission to execute a crawler, claim of factual answerability or policy
amendment. No other host is added to the approved allowlist.

## Untrusted context footprint
`audit_context_budget` accounts for both Unicode character and UTF-8 byte
footprints of selected **exact** retained passages, including host/source
concentration. Going beyond the campaign's selected-evidence character budget
or the explicit bounded text budget raises a hold; no content is injected
into a model or external prompt. The inspection's byte threshold is not the
model's actual token count.

## Human review throughput advisor
`plan_review_capacity(queue, lanes=4, budget_minutes=480)` computes a
deterministic hypothetical allocation of current review tasks to virtual
reviewer lanes, accounting for risk-weighted minutes. All unassigned work
remains visible; unaddressed critical findings are separately listed.
No real reviewer is assigned, no task is signed or closed, and no worker is
started. This optional planner is outside the twenty-stage content chain,
requiring separate authenticated human review under existing application
policy before any action.
