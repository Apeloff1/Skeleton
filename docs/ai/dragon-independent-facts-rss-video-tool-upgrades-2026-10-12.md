# Dragon research — signed factual consensus, RSS freshness and video tool research
2026-10-12 UTC. PR #3605. Feature branch only; not merged or deployed.

## Milestone A — Independently signed multi-source fact review
dragon_cross_source_factchecking.py introduces immutable ClaimSubject, SourceWitness and SignedClaimAdjudication receipts. Each source witness is bound to one tenant, canonical claim/context, exact source ID and revision hash, group-specific external auditor public key, observation time and support/contradiction/uncertainty judgment. The final adjudicator uses a different key and signs the exact canonical set of witnessed observations. Duplicate source IDs, reused signer keys, replayed/stale timestamps, missing signatures, cross-tenant claims, undisclosed contradictory sources, and withheld adjudications fail closed or produce a review-ineligible verdict.
Strict run_correlated_mother_to_shadow refuses to dispatch the existing 100-matrix mother-to-shadow worker until the independently witnessed claim set is corroborated. The original 100-matrix signatures, idle admission, human review and shadow/weight safety checks are not bypassed. A signature does not prove factual correctness or data rights; operator-provisioned source-trust roots and external fact research are required.

## Milestone B — Persistent idle RSS source scheduling
dragon_rss_freshness_scheduler.py keeps an owner-scoped SQLite source schedule with keyed HMAC event-chain receipts, compare-and-swap generation, restart-stable verification, separate policy-reference hashes, deterministic host jitter, capped exponential retry backoff, bounded 1h–7d polling intervals and per-host due-query quotas. Its due list is read-only and expressly not a crawling ticket. Record_poll requires the existing Updates hatchling idle ticket and re-checks admission before commit. Scheduler status never implies a feed snapshot was cryptographically verified here; actual feed intake still requires the signed RSS snapshot verification in dragon_rss_update_queue.py.
Adversarial tests cover tenant isolation, same-host fairness, retry/reset, stale generation, premature poll denial, worker preemption, no operator consent, malformed URLs, persistent state across restart, and HMAC journal tampering. The only observed Source Safety failure in the first run was an assertion expecting the word 'operator' in an existing rejection message; the message has been made explicit without reducing enforcement.

## Milestone C — Externally reviewed video tool/editor index
dragon_video_tool_research.py organizes real timecoded clips into editor/engine/build/art/audio/accessibility topics. Source packets derive from previously consented frame feature and transcript records; an independently provisioned video reviewer signs each packet digest and decision. The index binds clip/frame/source identities and note timecodes, detects repeated packets and clips, and ranks tool-related research leads against actual game-building topics. It does not invent video frames, establish product suitability, grant software licenses or train a model.

## Milestone D — Weekly multidisciplinary research upgrades
The existing weekly Markdown and JSON export now also supports software/editor lead indexes and independently corroborated or disputed article-claim reports, with digest checks and owner boundaries. It presents separate Software and Factcheck sections, preserving exact receipt/bookmark references and neutral unapproved labels. Unsafe Markdown/HTML punctuation from external observations is sanitized before use as a human-readable title. The command-line importer accepts the two optional payload families while retaining strict required receipt fields. Weekly automation still becomes schedule-active only after landing on the repository default branch and receiving trusted worker inputs.

All new components remain inactive unless a trusted caller supplies actual externally reviewed evidence and operator-owned keys. This pass adds no live network intake, does not grant publisher rights or change neural model weights, and does not merge PR #3605.
