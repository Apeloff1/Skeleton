# Wave 30 — Native research graph topology as source-bound evidence

GraphML, GEXF and a bounded DOT edge-list subset are now supported by
the original canonical Dragon CrawlRun source capture. These are
nonexecuting source formats: graph rendering, dynamic DOT attributes,
arbitrary source URLs, Graphviz invocation, external XML entities and
remote graph references are not followed.

A reusable deterministic graph kernel bounds at most 512 nodes and
1024 accepted unique graph arcs and measures directedness, weak
components, isolation, in/out degree, parallel arcs, self-loops,
SCC cycles and exact finite reverse reachability. The existing source
dependency graph SCC kernel is reused, but no source graph relation
is treated as a legal dependency, verified fact or network permission.

XML graph parsers reject DTD/ENTITY, unsupported roots, nested graphs,
dangling edges and source complexity beyond byte/element/depth caps.
DOT supports only primitive nodes and edges, declining markup, attribute
commands, subgraphs and arbitrary language expressions. Node labels,
raw source URLs and other metadata are never projected into retained
graph summaries; only bounded structural measurements and digest.

Every MIME value is explicitly admitted by existing immutable CrawlPolicy.
Original rights, tenant, consent, robots, public-IP/redirect and cost
controls remain. Code digest includes all graph modules. Real scripted
canonical tests verify rights, no extra outbound URLs and exact replay.
Source graph observations remain unreviewed and never trainable.
