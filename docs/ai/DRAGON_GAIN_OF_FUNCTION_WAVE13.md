# Dragon Wave 13 — Geospatial, API-contract and structured-dataset ingestion

The canonical bounded CrawlRun worker gains real in-scope acquisition and
inert evidence projection of GeoJSON, OpenAPI 3, JSON Schema and TSV.

GeoJSON validates WGS84 coordinates, vertex budgets and finite geometry.
Its retained bounds are deliberately coarsened. Only curated property labels
are projected; external URL fields and arbitrary feature metadata are omitted.

OpenAPI contracts project verb/path/operation summaries/response code lists,
not servers, auth schemes, request bodies, executable examples or remote refs.
JSON Schema projects only property names, declared types, required flags and
short descriptions: no untrusted remote schema resolution or evaluation.
TSV records remain inert cells with no formula execution or link discovery.

All supported MIME types are enumerated in the existing CrawlPolicy and are
included in code-digest admission. Strict UTF-8 parsing and bounded source
texts retain canonical source hashes and current consent/rights semantics.
No new network client, daemon, queue, store, external execution, additional
host permission or implicit knowledge promotion is introduced.

Real scripted canonical run_slice/replay regression tests cover all formats,
invalid structural input, redaction and zero unintended network requests.
Live network, Mongo, distributed-worker/device, full repository CI and release
qualification are separate unverified gates.
