# Dragon Wave 20 — Original game and vector scene-source intelligence

The canonical Dragon CrawlRun now accepts inert structural metadata for
SVG drawings, ASCII PLY and OFF meshes, Godot 4 scene text, Unity YAML
scene objects, ASCII USD prim graphs and LDraw part/primitive inventories.

These are genuine existing-run source extraction formats and text receipt
extensions, not new network clients, game engines, GPU renderers, asset
loaders, executable shader imports or source-rights permissions.

- SVG parses finite XML without DTD/ENTITY and rejects active script,
  foreignObject, animation/event handlers and overdeep/oversized structure.
  Images, links, webfonts and external resources are never loaded.
- PLY and OFF validate finite XYZ geometry, polygon arity, vertex indices,
  geometry extent and declared counts without importing or rendering meshes.
- Godot scenes expose node and resource class counts, not script bodies or
  resource paths. No scripts, shader resources or imported scenes are opened.
- Unity YAML is scanned as a finite object/class document, without YAML
  object construction, MonoBehaviour invocation or external file dereference.
- USDA reads declared prim types without reference composition or payload IO.
- LDraw reports primitive counts and part-ref counts without loading parts.

All retained evidence is still unreviewed, with exact wire/body/source
hashes and existing tenant/owner, consent, robots, host/DNS, request/byte,
source-rights, review and Mongo CAS authorities unchanged. New parser code
is included in the implementation digest. Limits and errors are fail-closed,
and rejected HTTP attempts retain cumulative accounting.

The source suite compiles all modules and exercises parser refusal cases,
as well as real scripted CrawlRun run_slice capture, source status and
snapshot replay for all seven families.

Live Internet, native GPU, physical game-engine installs, malware scanning,
Mongo distributed workers, full release gates and evidence-to-game approval
remain independent unqualified steps. This draft must not be merged or
released without those approvals.
