# Original studio execution and production plane

Stack: base catalog #4370, 32 source packets #4373–#4404, original quest/continuity/runtime drafts #4405–#4411, and 20 focused drafts #4412–#4431.

## What is executable

- The real source catalog contains 512 registered authored game briefs, with 8 linked sections each (4,096 documents); it does **not** contain finished native implementations of those 512 target genres.
- An authorized local quest runner executes authored stage choices with immutable replay digests. Both original `entry` and later `prerequisites` contracts are supported without inventing dependencies.
- Scene/object bindings, independent faction/social rules, strictly conserved sandbox resource quantities, canonical save/restore, and original source fingerprints provide deterministic *offline authoring simulation*.
- Art recipes, audio cue sheets, release obligations and work DAGs expose real outstanding tasks for Jeeves and the studio work manager. Work claims, media creation and rights evidence are never manufactured.
- Adaptive producer admission measures host RAM, disk and CPU; optionally requires independent GPU telemetry. No fixed project/file count limits govern production batching. Under resource pressure, jobs defer instead of being admitted dishonestly.
- `python -m scripts.studio_producer_cli --project studio_aerial_traversal_amber_highlands --scene arrival --object hazard_monitor` inspects the read-only production frame and playable authoring session.
- `python -m scripts.studio_producer_cli --project studio_arena_fighting_glacial_fjord --capacity-root . --working-set-bytes 1048576 --output-bytes 1048576` gives a local read-only resource plan.

## Hard release boundaries

No draft in this stack is consumer-certified or qualified as a native genre engine. The attached original project designs require actual asset generation, original/authorized audio, implemented physical genre mechanics, complete branches/endings, authorized operator review, device qualification, and exact-head CI/security gates. A sandbox intent is not real object interaction. A source SHA-256 is not a signed external attestation. An in-memory worker lease is not distributed execution or completion proof.

Review and merge these stacked branches in dependency order. Never count skipped, queued, cancelled, or superseded checks as passing.
