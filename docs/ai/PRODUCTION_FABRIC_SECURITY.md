# Production fabric security boundaries

1. **Data is never authority.** Source text, LLM answers, retrieved evidence, tool output and imported world documents cannot mint an operator grant or register executable callbacks. Only explicit `issue(..., operator_authorized=True)` establishes a grant; real applications must bind that boolean to independently authenticated operator state rather than user-controlled JSON.
2. **No automatic external side effects.** The tool callback registry requires typed registrations and risk classification. External writes require explicit out-of-band approval. The outbox queues receipts; it never executes callbacks or performs network requests.
3. **Durability is scoped.** The local SQLite journal enforces an event hash chain and revision CAS, with restart reconstruction from events. It is not a globally linearizable multi-replica journal. The SQLite path must be on a trusted operator-owned filesystem; symlinked directory replacement is not protected by sqlite3.
4. **No untrusted archive extraction.** Import/export accepts canonical JSON world descriptions; it does not unzip arbitrary packages, execute imports derived from input strings, or create arbitrary files from archive members.
5. **Rights are a hold.** All included story text is synthesized as original in the project, but full provenance, redistribution clearance, possible similarity and independent legal review remain unverified. The rights gate requires independent review, source and redistribution authorization.
6. **Bounded execution.** Static world size, graph size, source length, token planning estimate, route search, state-space traversal and benchmark input have limits. Bounded exhaustion fails closed rather than claiming success.
7. **Correctness boundary.** Focused tests demonstrate only listed behaviors. They do not attest correctness of large frontier model inference, Windows/macOS laptop operation, GPU placement, full feature parity, consumer releases or security under a hostile multi-tenant runtime.
