# AI-only ownership and integration boundaries

Native Genesis belongs to the offline AI/model runtime domain.
It may reference `skeleton.cortex.TinyTransformer`, the existing
`native_candidate` training engine and original `native_qualification`
benchmark inventory, but must not introduce or modify gameplay,
world scenes, NPCs, quests, user-authored game assets or game installation.

The layer's responsibilities are original-data tokenizer construction,
bounded native initialization, model/corpus identity, immutable checkpoint
custody, native graph smoke proof, candidate-only SGD invocation and real
paired model evaluation.

The builder/game production studios remain separate. Game output may later
use independently qualified AI serving interfaces, but game content is not
part of this training corpus and supplies no implicit model-training rights.

The source, training, evaluation, admission and release authorities are
separate systems. Changes to this layer must remain draft until their
relevant higher-level contracts and exact-head repository gates pass.
