# Independent canonical graph review writers

New canonical graph provisioning installs a version-bound independent writer marker and lane-local immutable review receipts. Existing canonical layouts can opt in offline using python -m core.dragon_graph_authority enable-direct-writers --root /private/corpus/root.db --offline-writers-stopped. Stop every old writer and back up the eleven files coherently. This upgrade atomically activates ten local write ledgers; earlier root replay receipts remain read-only history.

Review state and next-review deadline are authoritative fields in the real graph node table, changed in one selected lane transaction together with its replay receipt and sequence. A root shared rollback-journal read transaction fences current owner enablement, directory membership, historic receipt identity and topology. Local writes on different lanes can overlap; root structural writers may contend and fail closed on timeout. Cross-lane canonical queries pin every lane read lock before returning a merged page. New replay events are limited to 20 million per owner and lane; no automatic deletions. Old binary downgrade is unsupported. An absent selected lane prevents publication rather than recreating it.

The existing authenticated editor review endpoint uses the independent writer when enabled. New POST /knowledge/game-corpus/lead-graph/review-batch accepts at most 32 fully validated items, each with lead, decision, reason, operation and interval_seconds. At most four lane groups run concurrently with ordering within each lane. Results are per-item committed, held or missing; successful items are not undone by unrelated holds. Replay identical operations safely. No fetch, rights grant, or source verification authority is delegated. Status distinguishes ten review writers from the still-coordinated structural writer.
