# Dragon Wave 16 — Extended binary source and media boundary

Eight additional classes are admitted through the original canonical
bounded CrawlRun worker: WebP image headers, FLAC STREAMINFO, Opus Ogg
identification headers, MP4 movie headers, GLB binary scene manifests,
binary STL triangles, Windows ICO image directories and TAR archive
inventories. Each uses a distinct finite source parser and negative tests.

These scanners do not decompress or render images/audio/video, parse DRM,
play media, decode geometry buffers, load external textures, inspect codecs,
extract archive members, execute scripts, or disclose raw external metadata
without the existing owner, consent, rights, robots, DNS, budget and
worker-lease boundaries. TAR links and path traversal are denied. GLB
checks chunk order and invokes the already bounded glTF JSON graph checker.

A dedicated scripted CrawlRun test runs every MIME through actual robots
admission, request/byte accounting, retained-source provenance, exact
snapshot replay and no extra request. The source workflow compiles and
executes eight parser-specific negative suites and this canonical integration
suite. All source text remains unreviewed, never training-authorized.

No native media interpretation, live Internet, distributed Mongo worker,
physical device, complete repository CI, merge or launch is claimed.
