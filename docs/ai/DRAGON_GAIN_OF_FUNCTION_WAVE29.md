# Wave 29 — Service contract topology without executing remote methods

GraphQL introspection JSON, AsyncAPI 2.6/3.0 event contracts and proto3
declarations become bounded, inert canonical Dragon source types.

GraphQL: type/field/argument and root categories, finite directed named
type edges, strong cycles and reverse impact measured through the shared
SBOM topology kernel. GraphQL mutations, subscriptions and introspection
requests are never issued; type names are unreviewed external claims.

AsyncAPI: finite channels, local message reference counts, send/receive
or publish/subscribe declarations, unresolved references and source
contract fingerprint. No message broker connection, publish, subscribe,
credential negotiation, schema import or remote reference resolution.

Proto3: finite lexical message/enum/service/RPC declarations and
package labels; the text is never compiled and source-declared imports
are not dereferenced. Unknown or foreign syntax does not grant execution.

These formats use existing strict UTF-8 decoding, source-rights checks,
canonical CrawlRun request admission, robots/DNS, original owner consent,
request and byte accounting, source provenance and snapshot hashing.
Source code is included in the runtime implementation digest. Tests cover
direct negative inputs, no external references, canonical capture and
snapshot replay. Nothing constitutes a reviewed service contract,
credential authorization, training license or production readiness.
