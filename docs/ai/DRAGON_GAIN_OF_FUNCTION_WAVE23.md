# Wave 23 — Structured HTML evidence without external ontology execution

The original canonical HTML capture now adds bounded, inert observations
of Microdata, limited RDFa and Microformats2 item/property declarations.
Visible author, headline, publication, description and software labels
enter retained unreviewed evidence. Source itemtypes are only recognized
as syntax, not resolved against remote schema/ontology services.

Unlike general HTML parsing, structured annotations never use href, src,
content, itemid, external ontology, media or URLs as an acquisition hint.
Script, iframe, SVG, template and foreign content is excluded. The parser
has finite tag, nesting, property, item and retained text bounds.

Source rights, consent, robots, DNS/socket policy, URL admission and Mongo
snapshot revision are unchanged. Annotation failures cannot override
canonical page capture authority or enable any additional request.
Regression tests cover three vocabularies, privacy and complexity denial,
actual run_slice source custody, noarchive precedence and snapshot replay.
