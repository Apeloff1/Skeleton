## Implemented original mechanics
The locally supervised editor exports independently playable Godot 4 physics scenes from source-verified platformer hazards, racing obstacles and sandbox-world ridges/buildings. Real native GDScript independently executes approved source-bounded force, gravity, collision-layer, static-fixture, angular and objective rules. It does not replay rendered Python animation.

The native project includes the original scene/session/head digests, source game action history, original witness IDs, source physics-session digest and complete Python-Godot proof. A GDScript provenance hook requires its original-genre binding to match the accompanying original source record before replay and then independently verifies physical state.

The profile is intentionally one 2D AABB body, up to eight zero-angle authored obstacles, and approved finite actions. Advanced Python rotational, 3D, multi-body and fluid mechanics remain outside native parity. This is a physical encounter port, not a full native platformer, racing, or sandbox game: all source genre score, HP, quests, economy and progression remain governed by the existing original Python engines. The linked campaign remains opt-in with a distinct gameplay authority.

## User workflow
Choose a signed original platformer, racing or sandbox advanced session and select Download original physical encounter for Godot 4. The server authenticates the session and scene, reconstructs every physics event, verifies the strict native profile, then returns the original Godot project and release manifest as a bounded deterministic ZIP. No file is overwritten or released automatically.
