# answer_grounding — evidence-bound model quality

Exact-byte citations without a false semantic entailment claim.

This family is a read-only evaluation projection on the existing operational
AI and supervised GGUF source owners. It does not invoke a new provider,
generate a synthetic benchmark, change system prompts, or mint a promotion
or model-install approval. Every source must preserve its original rights
approval, model/tokenizer identity and independent evaluator digest.

Source profile: mode hybrid, 10752 token
planning estimate, 83968 byte budget, 55000ms
nominal wall budget, minimum 4 independent evidence rows.
The 20 canonical bounded operation interfaces are retained with an external-
evidence-aware quality entrypoint and original-source casebook tests.

Failure: refuse malformed input, missing evaluator/model ID, unfounded
semantic claim, forged original-byte citation, duplicate benchmark ID,
nonfinite score, invalid model answer shape, or unapproved promotion. p95/p99
requires genuine independent samples, not synthesized source casebooks.
Keep release, rights, laptop and native inference acceptance as separate holds.
