# Moonlit Breakwater: The Navigator's Harbor Charter

**Original chapter 35/49 · Moonlit Breakwater · Navigator**

## Situation

In a drowned port exposed at the edge of the lunar tide, the navigator must synchronize the return route to the signal using a star-and-current sextant. The harbor mirror grows unreliable near the route's
central hazard, while the lighthouse revenant contests the outer branch.

## Playable route and consequences

The main causeway links **S → K → H → O → R → E**. The source key must
precede the objective; the objective must precede exit. The main route
is available without random rolls. The optional cache, medicine, and recharge
locations let players mitigate scarce health and energy.

The branch at **F** tests diplomacy with Night Harbor Guild. The **?** choice
records a distinct reputation outcome, and **L** preserves testimony
about the Harbor Charter. The guardian detour presents the lighthouse revenant;
its damage is defined in the versioned encounter contract.

## Authored dilemma and closure

Whether to accept an unverified coordinate? Choosing to seek
public witness yields the prospect of a verified return bearing; preserving the
record instead emphasizes integrity. Recover the Harbor Charter and return with the verified return bearing; Night Harbor Guild can finally verify the source testimony.

## Determinism and evidence

All movement is explicit and bounded. Reloaded saves must reproduce every
command against the same source digest; no external service or procedural
unseeded randomness can rewrite the result. Domain-specific presentation
remains future work, not an already-qualified render or device build.
