# Ember Orchard: The Navigator's Seed Archive

**Original chapter 28/49 · Ember Orchard · Navigator**

## Situation

In a volcanic garden whose fruit germinates in cooling ash, the navigator must synchronize the return route to the signal using a star-and-current sextant. The cinder lantern grows unreliable near the route's
central hazard, while the ashwood guardian contests the outer branch.

## Playable route and consequences

The main causeway links **S → K → H → O → R → E**. The source key must
precede the objective; the objective must precede exit. The main route
is available without random rolls. The optional cache, medicine, and recharge
locations let players mitigate scarce health and energy.

The branch at **F** tests diplomacy with Orchard Keepers. The **?** choice
records a distinct reputation outcome, and **L** preserves testimony
about the Seed Archive. The guardian detour presents the ashwood guardian;
its damage is defined in the versioned encounter contract.

## Authored dilemma and closure

Whether to accept an unverified coordinate? Choosing to seek
public witness yields the prospect of a verified return bearing; preserving the
record instead emphasizes integrity. Recover the Seed Archive and return with the verified return bearing; Orchard Keepers can finally verify the source testimony.

command against the same source digest; no external service or procedural
