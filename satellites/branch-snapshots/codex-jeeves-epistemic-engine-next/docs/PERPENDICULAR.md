# Perpendicular cut

Linear growth thickens the last file. A perpendicular cut walks seven
axes at once so title-space, forge-space, law-space and mouth-space
name the same object.

## Axes

| Axis | Module | Contract |
|---|---|---|
| REF | `cortex/refs.py` | pointer + citation, `stored_prose=0` |
| ERA | `cortex/era_bind.py` | `cozy` → `cozy_wholesome`; `like Elden Ring` → `soulslike` |
| LAW | `cortex/laws.py` | `check()` fail-closed |
| TEACH | `cortex/contact.py` | HF / Kimi copies get LoRA + SGD + Hebb + absorb |
| ASCEND | `cortex/improve.py` | `like <title>` trains house mouths only |
| GENOS | `cortex/genos.py` | one pulse, M clipped |
| OBSERVE | `jeeves/core.py` | card carries G + law + citation |
