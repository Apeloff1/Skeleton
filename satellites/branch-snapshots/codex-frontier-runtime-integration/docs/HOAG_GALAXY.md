# Hoag Galaxy — internal knowledge organism

Five brains around a wiki nucleus. Colored rings. LLM mouths live in the
dark gap and only touch the nucleus through Jeeves.

Cite the object, do not copy Hubble captions:
https://science.nasa.gov/image-detail/idl-tiff-file-43/

## Brains

| # | Brain     | Color   | Job |
|---|-----------|---------|-----|
| 1 | memory    | cyan    | capture, write-route skip/new/update |
| 2 | compiler  | amber   | second-brain compile → zettel + PARA bucket |
| 3 | dream     | violet  | stores dreams; replay / prune / abstract |
| 4 | distiller | gold    | one principle per lesson; overwrite contradictions |
| 5 | editor    | sage    | traffic control + master index + freshness |

Each brain has a librarian. All librarians report to the wiki librarian
(yellow nucleus).

## Codec / decoder

Tiers T0_FLASH → T5_INDEX. Long-form conversation is a spine of
principles with flash leaves. Decoder reconstructs house dialect from
atom priors (blend knob). Critical / low-confidence atoms pass through.
